Projets

Une sélection de projets académiques et appliqués en Data, BI et Bases de données.

Axiora — Analyse, ML & Génération Automatique de Rapports (Données HCP)

Plateforme data basée sur des données socio-économiques (HCP) combinant analyse exploratoire, modèles de Machine Learning et un module de questions-réponses pour interroger les indicateurs et obtenir des résultats interprétables.

Le projet intègre aussi un générateur de rapports qui produit automatiquement des synthèses (insights, tendances, comparaisons régionales) prêtes à être partagées.

Concepts : EDA, feature engineering, régression/classification, validation croisée, Q&A analytique, reporting automatique.

Outils : Python (Pandas, NumPy, Scikit-Learn), Streamlit, Matplotlib/Seaborn, Git/GitHub.

Dashboard Décisionnel – Analyse des Performances Carrefour 2020

Conception d’un tableau de bord interactif basé sur les données commerciales Carrefour 2020 afin de suivre les indicateurs clés de performance (KPIs).

Le dashboard permet l’analyse des ventes par région, catégorie et période, la visualisation des tendances ainsi que l’identification des segments les plus rentables.

Concepts : Data modeling, KPIs, Mesures DAX, Segmentation, Visual storytelling.

Outils : Power BI, SQL.

Base de Données PL/SQL – Application de Gestion Immobilière

Conception et implémentation d’une base de données relationnelle destinée à gérer une application de location de biens immobiliers.

Le système intègre la gestion des clients, biens et contrats, le suivi des paiements ainsi que l’utilisation de procédures stockées et déclencheurs (triggers) pour garantir l’intégrité des données.

Concepts : Modélisation MCD/UML, Normalisation, Procédures stockées, Triggers, Contraintes et Transactions.

Outils : Oracle SQL / PL-SQL.
