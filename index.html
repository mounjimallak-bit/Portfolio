Final-year project Internship — Albarray Consulting · Individual · 2026

Photovoltaic anomaly detection with a real-time scoring pipeline

Photovoltaic plants degrade quietly. Soiling, shading and inverter faults cut output for weeks before anyone notices, and labelled fault data is almost never available. This project detects those faults without labels, then scores incoming measurements as they arrive.

Approach

An unsupervised ensemble of eleven models — one Isolation Forest, five dense autoencoders and five LSTM autoencoders, each trained on a different seed. Their reconstruction errors are converted to ranks and fused, which keeps the ensemble stable when individual models disagree. The decision threshold was selected by maximising F2 on a validation split, favouring recall: a missed fault costs more than a false alarm.

Deployment

The trained system runs as a streaming pipeline. A replayer publishes five-minute measurements to Kafka, a Python consumer scores each point and writes to TimescaleDB, and a provisioned Grafana dashboard renders the result live. The whole stack starts from a single docker compose up, dashboard included.

Personal project Individual · 2025

Axiora Data — socio-economic analytics platform

Morocco's national statistics institute publishes its data as spreadsheets, which makes comparison across regions slow. Axiora loads those tables and turns them into an interactive platform covering six domains: population, labour, housing, finance, education and poverty.

It renders choropleth maps at regional and provincial level from official boundary shapefiles, extrapolates indicator trends by linear regression, and generates formatted PDF reports from any uploaded dataset. A conversational module built on the Gemini API answers questions about the loaded indicators in plain language.

Streamlit · pandas · GeoPandas · Plotly · scikit-learn · fpdf · Gemini API

Carrefour sales analysis — end-to-end BI

A full business-intelligence workflow on retail transaction data, built as a layered pipeline rather than a single report file.

A Python ETL script cleans and standardises the raw transactions into an analysis-ready dataset. That feeds a Power BI semantic layer modelled as a star schema — one fact table for sales, six dimensions for date, product, customer, city, payment and category. KPIs are defined as DAX measures on top, driving an interactive dashboard for revenue, discount impact and category performance.

About

I am in my final year of an engineering degree in Data Science, Big Data and Artificial Intelligence at ENSA Agadir, Morocco. My work sits where statistical modelling meets engineering: not only whether a model performs, but whether it survives contact with a production data stream.

That interest came from a practical problem. Labelled failure data is rare in industrial settings, so the useful question is usually how to detect something abnormal without ever having been shown what abnormal looks like. Unsupervised anomaly detection on time series is what I want to keep working on at Master's level.

Before my final-year project I interned at Morocco's High Commission for Planning, working on report automation and applied machine learning. I work in French, English and Arabic.
