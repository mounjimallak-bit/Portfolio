Photovoltaic anomaly detection with a real-time scoring pipeline

Photovoltaic plants degrade quietly. Shading and other partial faults cut output for days or weeks before anyone notices, and labelled fault data is almost never available. This project detects shading faults without training on any labelled fault, then scores incoming measurements as they arrive.

Approach

An unsupervised ensemble of ten networks: five dense autoencoders and five LSTM autoencoders, each trained on a different seed. An Isolation Forest served as the baseline and was left out of the final system, because adding it lowered the fused score. Their reconstruction errors are converted to ranks and fused, which keeps the ensemble stable when individual models disagree. The decision threshold was selected by maximising F2 on a validation split, favouring recall: a missed fault costs more than a false alarm.

Deployment

The trained system runs as a streaming pipeline. A replayer publishes five-minute measurements to Kafka, a Python consumer scores each point and writes to TimescaleDB, and a provisioned Grafana dashboard renders the result live. The whole stack starts from a single docker compose up, dashboard included.

Results

PR-AUC (test)0.7765
Recall0.973
Precision0.703
Points scored2,813

Evaluated on a held-out partition never seen during training or threshold selection. Dataset: public Zenodo record of a 4 kW PV installation in La Réunion, with labelled shading faults, provided by the project supervisor.

Axiora Data: socio-economic analytics platform

Morocco's national statistics institute publishes its data as spreadsheets, which makes comparison across regions slow. Axiora loads those tables and turns them into an interactive platform covering six domains: population, labour, housing, finance, education and poverty.

For the Souss-Massa region, it renders choropleth maps at provincial and commune level from official boundary shapefiles, extrapolates indicator trends by linear regression, and generates formatted PDF reports from any uploaded dataset. A conversational module built on the Gemini API answers questions about the loaded indicators in plain language.

Streamlit · pandas · GeoPandas · Plotly · scikit-learn · fpdf · Gemini API

About

I am in my final year of an engineering degree in Data Science, Big Data and Artificial Intelligence at ENSA Agadir, Morocco. My work sits where statistical modelling meets engineering: not only whether a model performs, but whether it still works when it scores a live data stream.

That interest came from a practical problem. Labelled failure data is rare in industrial settings, so the useful question is usually how to detect something abnormal without ever having been shown what abnormal looks like. Unsupervised anomaly detection on time series is what I want to keep working on, first in my end-of-studies internship, then at Master's level.

Before my PFA internship I interned at Morocco's High Commission for Planning, working on report automation and applied machine learning. I work in French, English and Arabic.
