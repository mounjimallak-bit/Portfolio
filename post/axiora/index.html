Introduction

Contexte

Les indicateurs socio-économiques constituent un levier essentiel pour la compréhension du développement territorial et la prise de décision stratégique. Axiora Data a été développé comme une plateforme intelligente d’analyse, de visualisation et de prévision des indicateurs socio-économiques régionaux basés sur les données du HCP.

Problématique

Les données publiques sont souvent statiques (PDF, tableaux bruts), ce qui limite l’exploration interactive, la comparaison multi-années et la projection des tendances futures. Il existe donc un besoin d’un outil interactif, dynamique, prédictif et orienté aide à la décision.

Vision

Axiora Data est une plateforme d’intelligence socio-économique combinant Data Analytics, Visualisation avancée, Intelligence artificielle, Géospatial et automatisation de reporting.

Aperçu de la plateforme

Objectifs

  • Centraliser et structurer les indicateurs socio-économiques (HCP) pour la région Souss-Massa.
  • Permettre une exploration interactive (années, provinces, communes, indicateurs).
  • Faciliter la comparaison multi-années et multi-territoires (variation %, tendances).
  • Intégrer un module de prévision (ML) pour projeter l’évolution des indicateurs.
  • Renforcer l’aide à la décision via un assistant IA et des rapports automatiques.

Fonctionnalités clés

  • Dashboard : indicateurs synthétiques et vues rapides.
  • Exploration des indices : Population, Travail, Habitat, Finance, Enseignement, Pauvreté.
  • Filtres dynamiques : année, province/commune, type d’indicateur, mode comparaison.
  • Visualisations interactives : courbes, barres, heatmaps, scatter, tableaux.
  • Cartes géographiques : choroplèthes pauvreté/vulnérabilité avec tooltips & zoom.
  • Prévisions ML : projection de tendances et visualisation des prédictions.
  • Assistant IA : réponses, résumés et interprétation des résultats.
  • Rapports PDF : génération automatique avec graphiques + cartes + synthèse.

Le fichier RGPH contient les informations démographiques détaillées par territoire : codes administratifs, superficie, population légale, population municipale, structure par sexe et répartition par classes d’âge.

3) Préparation des données : étapes et logique

A — Lecture et copie de travail

Lecture des fichiers Excel en conservant les valeurs brutes en texte (évite les conversions implicites). On crée ensuite une copie de travail destinée aux transformations. 

import pandas as pd

rgph_raw = pd.read_excel("RGPH2014.xlsx", sheet_name=0, dtype=str)
pauv_raw = pd.read_excel("chtouka pauvr.xlsx", sheet_name=0, dtype=str)

rgph = rgph_raw.copy()
pauv = pauv_raw.copy()

B — Normalisation des noms de colonnes

Standardiser les noms pour éviter les variations (espaces multiples, accents, “Km²”, etc.). Objectif : obtenir des clés stables (ex. population_legale, supereficie_km2). 

import re

def norm_col(c):
    c = (c or "").strip()
    c = re.sub(r"\s+", " ", c)
    c = c.replace("²", "2").replace("%", "pct").replace("-", "_")
    c = c.lower()
    c = re.sub(r"[^a-z0-9_ ]", "", c).replace(" ", "_")
    return c

rgph.columns = [norm_col(c) for c in rgph.columns]
pauv.columns = [norm_col(c) for c in pauv.columns]

C — Conversion fiable des valeurs numériques

Conversion des formats fréquents : séparateurs d’espace (ex. 421 844), virgule décimale (ex. 10,2), et pourcentage (ex. 50,3%). Les valeurs vides sont converties en NA. 

import pandas as pd
import re

NBSP = "\u00A0"
NNBSP = "\u202F"

def to_number(x):
    if x is None:
        return pd.NA
    s = str(x).strip()
    if s == "" or s.lower() in {"na","n/a","nan","none"}:
        return pd.NA
    s = s.replace("%", "")
    s = s.replace(NNBSP, "").replace(NBSP, "").replace(" ", "")
    s = s.replace(",", ".")
    s = re.sub(r"[^0-9\.\-+]", "", s)
    if s in {"", ".", "-", "+"}:
        return pd.NA
    try:
        v = float(s)
        return int(v) if v.is_integer() else v
    except ValueError:
        return pd.NA

text_cols = {"conc", "localites"}
num_cols = [c for c in rgph.columns if c not in text_cols]
for c in num_cols:
    rgph[c] = rgph[c].map(to_number)

D — Gestion des lignes hiérarchiques / valeurs manquantes

Certaines lignes représentent des niveaux administratifs (ex. “Rural”, “Centre”) parfois sans valeurs. On les identifie pour éviter de fausser les calculs, tout en gardant l’information si nécessaire. 

def row_is_empty_numeric(df, numeric_columns):
    return df[numeric_columns].isna().all(axis=1)

numeric_cols = [c for c in rgph.columns if c not in {"conc","localites"}]
rgph["is_empty_row"] = row_is_empty_numeric(rgph, numeric_cols)

rgph_analysis = rgph.loc[~rgph["is_empty_row"]].copy()

E — Contrôles qualité (cohérence)

Vérifications rapides pour détecter incohérences (ex. parts Homme/Femme proches de 100, population municipale non supérieure à la légale, etc.). Les flags aident à repérer les lignes à inspecter. 

def approx_sum(df, cols, tol=2.0):
    s = df[cols].sum(axis=1, skipna=False)
    return (s.between(100 - tol, 100 + tol)) | s.isna()

if {"part_mas","part_fem"}.issubset(rgph_analysis.columns):
    rgph_analysis["qc_sex_100"] = approx_sum(rgph_analysis, ["part_mas","part_fem"], tol=2.0)

if {"population_legale","population_municipale"}.issubset(rgph_analysis.columns):
    rgph_analysis["qc_pop_ok"] = rgph_analysis["population_municipale"] <= rgph_analysis["population_legale"]

F — Export final (formats utiles)

Export en CSV/Parquet/JSON pour faciliter l’analyse et l’intégration. Le JSON peut être structuré par localité (clé = code si présent) pour un accès direct. 

from pathlib import Path
import json
import pandas as pd
import re

out_dir = Path("outputs")
out_dir.mkdir(exist_ok=True)

rgph_analysis.to_csv(out_dir / "rgph_clean.csv", index=False, encoding="utf-8")
rgph_analysis.to_parquet(out_dir / "rgph_clean.parquet", index=False)
rgph_analysis.to_json(out_dir / "rgph_clean.json", orient="records", force_ascii=False)

def build_dict(df):
    out = {}
    for _, r in df.iterrows():
        code = str(r["conc"]) if "conc" in df.columns else None
        name = str(r["localites"]) if "localites" in df.columns else None
        k = code if code and code != "<NA>" else name

        age = {}
        for c in df.columns:
            if c in {"m15ans","15_59_ans","60ans_et_plus"} or re.match(r"^\d+_\d+_ans$", c):
                age[c] = r[c] if pd.notna(r[c]) else None

        out[k] = {
            "code": code,
            "localite": name,
            "population_legale": r.get("population_legale", None),
            "population_municipale": r.get("population_municipale", None),
            "supereficie_km2": r.get("supereficie_km2", None),
            "part_mas": r.get("part_mas", None),
            "part_fem": r.get("part_fem", None),
            "age": age
        }
    return out

rgph_dict = build_dict(rgph_analysis)
with open(out_dir / "rgph_dict.json", "w", encoding="utf-8") as f:
    json.dump(rgph_dict, f, ensure_ascii=False, indent=2)
