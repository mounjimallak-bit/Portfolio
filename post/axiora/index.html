Axiora — Application d’analyse (Streamlit)

Interface interactive pour explorer des données, visualiser et produire des insights.

Contexte

Projet orienté valorisation des données : nettoyage, exploration, visualisation, et restitution via une application web simple à utiliser.

Objectifs

  • Permettre l’exploration rapide (EDA) via une interface.
  • Afficher des visualisations claires et des indicateurs clés.
  • Rendre le projet facilement partageable (démo web).

Stack & Outils

  • Python (Pandas, NumPy)
  • Visualisation (Plotly / Matplotlib)
  • Streamlit (UI + déploiement)
  • Git/GitHub

Résultats

  • Navigation simple (filtres, vues, graphiques).
  • Indicateurs + visualisations lisibles.
  • Application présentable pour un recruteur.
