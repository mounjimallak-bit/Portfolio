Introduction

Contexte

Les indicateurs socio-économiques constituent un levier essentiel pour la compréhension du développement territorial et la prise de décision stratégique. Axiora Data a été développé comme une plateforme intelligente d’analyse, de visualisation et de prévision des indicateurs socio-économiques régionaux basés sur les données du HCP.

Problématique

Les données publiques sont souvent statiques (PDF, tableaux bruts), ce qui limite l’exploration interactive, la comparaison multi-années et la projection des tendances futures. Il existe donc un besoin d’un outil interactif, dynamique, prédictif et orienté aide à la décision.

Vision

Axiora Data est une plateforme d’intelligence socio-économique combinant Data Analytics, Visualisation avancée, Intelligence artificielle, Géospatial et automatisation de reporting.

Aperçu de la plateforme

Objectifs

  • Centraliser et structurer les indicateurs socio-économiques (HCP) pour la région Souss-Massa.
  • Permettre une exploration interactive (années, provinces, communes, indicateurs).
  • Faciliter la comparaison multi-années et multi-territoires (variation %, tendances).
  • Intégrer un module de prévision (ML) pour projeter l’évolution des indicateurs.
  • Renforcer l’aide à la décision via un assistant IA et des rapports automatiques.

Fonctionnalités clés

  • Dashboard : indicateurs synthétiques et vues rapides.
  • Exploration des indices : Population, Travail, Habitat, Finance, Enseignement, Pauvreté.
  • Filtres dynamiques : année, province/commune, type d’indicateur, mode comparaison.
  • Visualisations interactives : courbes, barres, heatmaps, scatter, tableaux.
  • Cartes géographiques : choroplèthes pauvreté/vulnérabilité avec tooltips & zoom.
  • Prévisions ML : projection de tendances et visualisation des prédictions.
  • Assistant IA : réponses, résumés et interprétation des résultats.
  • Rapports PDF : génération automatique avec graphiques + cartes + synthèse.

2) Préparation des données : étapes & logique

A — Lecture & normalisation des colonnes

Les fichiers Excel contiennent parfois des formats hétérogènes (séparateurs, espaces, pourcentages, valeurs manquantes). Cette étape harmonise les noms de colonnes et prépare un schéma stable (mêmes variables, mêmes intitulés) pour toute la plateforme.

B — Conversion numérique contrôlée

On convertit uniquement les colonnes attendues en numérique (superficie, populations, parts, âges). Les symboles (%, espaces, séparateurs) sont supprimés avant conversion. Les valeurs non convertibles deviennent NaN (gérées ensuite) pour éviter les erreurs silencieuses.

C — Gestion des valeurs manquantes

Certaines lignes (ex. “Rural” ou lignes administratives) peuvent avoir des champs vides. La règle : conserver la ligne si elle a un intérêt territorial, mais marquer les champs manquants proprement. Les calculs et visualisations utilisent ensuite des filtres/contrôles pour éviter les biais.

D — Structuration “finale” pour consommation

Après nettoyage, les données sont exportées sous forme de fichiers structurés (CSV/JSON). Dans AXIORA, cela permet : filtres rapides, cartes, agrégations, comparaisons, et génération de rapports automatiques. 

# Cleaning pipeline (exemple robuste et réutilisable)
import pandas as pd
import numpy as np
import re
import json

def normalize_colname(c: str) -> str:
    c = str(c).strip()
    c = re.sub(r"\s+", " ", c)
    return c

def to_number(x):
    if pd.isna(x):
        return np.nan
    s = str(x).strip()
    # enlever espaces insécables + espaces normales
    s = s.replace("\u202f", "").replace("\u00a0", "").replace(" ", "")
    # enlever %
    s = s.replace("%", "")
    # virgule décimale -> point
    s = s.replace(",", ".")
    # garder chiffres / point / signe
    s = re.sub(r"[^0-9\.\-]", "", s)
    try:
        return float(s) if s != "" else np.nan
    except:
        return np.nan

# ---- 1) Lecture RGPH
rgph_path = "RGPH2014.xlsx"
df_rgph = pd.read_excel(rgph_path)

# Normaliser colonnes
df_rgph.columns = [normalize_colname(c) for c in df_rgph.columns]

# Colonnes à convertir (adapter aux noms exacts du fichier)
num_cols_rgph = [
    "Supereficie Km²",
    "Population légale",
    "Population municipale",
    "Part Mas", "Part Fem",
    "0-4 ans", "5-9 ans", "10-14 ans",
    "M15ans", "15-59 ans",
    "15-19 ans", "20-24 ans", "25-29 ans", "30-34 ans", "35-39 ans",
    "40-44 ans", "45-49 ans", "50-54 ans", "55-59 ans",
    "60ans et plus"
]

for c in num_cols_rgph:
    if c in df_rgph.columns:
        df_rgph[c] = df_rgph[c].apply(to_number)

# Nettoyage minimal des identifiants
if "CONC" in df_rgph.columns:
    df_rgph["CONC"] = df_rgph["CONC"].astype(str).str.strip()

# ---- 2) Lecture Pauvreté
pauv_path = "chtouka pauvr.xlsx"
df_pauv = pd.read_excel(pauv_path)
df_pauv.columns = [normalize_colname(c) for c in df_pauv.columns]

# Exemple : convertir toutes colonnes sauf identifiants en numérique
id_cols = [c for c in df_pauv.columns if "code" in c.lower() or "conc" in c.lower() or "local" in c.lower()]
for c in df_pauv.columns:
    if c not in id_cols:
        df_pauv[c] = df_pauv[c].apply(to_number)

# ---- 3) Export JSON (pour affichage dictionnaire dans la page)
final_rgph = df_rgph.fillna("").to_dict(orient="records")
final_pauv = df_pauv.fillna("").to_dict(orient="records")

with open("final_rgph.json", "w", encoding="utf-8") as f:
    json.dump(final_rgph, f, ensure_ascii=False, indent=2)

with open("final_pauvrete.json", "w", encoding="utf-8") as f:
    json.dump(final_pauv, f, ensure_ascii=False, indent=2)
